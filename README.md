# Duplicate Question Pairs Detection  

## 📌 Overview  
This project focuses on detecting whether two given questions are duplicates. Inspired by the famous Quora Question Pairs problem, the goal is to build a Natural Language Processing (NLP) pipeline that classifies question pairs as *duplicate* or *non-duplicate*.  

## 🛠 Features  
- **Exploratory Data Analysis (EDA):** Data distribution, imbalance handling, and text inspection.  
- **Text Preprocessing:** Tokenization, stopword removal, lowercasing, and normalization.  
- **Feature Engineering:**  
  - Bag of Words (BoW)  
  - TF-IDF Vectorization  
  - Simple & Advanced similarity features (cosine similarity, word overlap, etc.)  
- **Machine Learning Models:** Logistic Regression, Random Forest, XGBoost, etc.  
- **Evaluation Metrics:** Accuracy, Precision, Recall, F1 Score, AUC.  
- **Deployment Ready:** Contains `requirements.txt`, `setup.sh`, and modularized code (`helper.py`, `app.py`).
